# Как вести каталог (шпаргалка для себя)

Публичная страница — `README.md` (её видят люди на GitHub). Источник правды — `catalog.json`.
README **не правим руками** — он собирается из `catalog.json` скриптом.

## Добавить инструмент
```
python3 add.py <ссылка на GitHub> --cat <раздел> --aud me|public --desc "описание по-русски"
```
- `--cat` — раздел: `ai-text` `ai-image` `agents` `scraping` `dev-tools` `skills` `other`
- `--aud me` — тащим и к себе, и в каталог (значок ⭐) · `--aud public` — только в каталог
- `--desc` — короткое описание по-русски (если забыть — встанет английское с GitHub, потом поправишь)
- звёзды/язык/имя подтягиваются с GitHub сами; README пересобирается автоматически

Пример:
```
python3 add.py https://github.com/ollama/ollama --cat ai-text --aud public --desc "Запуск нейросетей локально на компе."
```

## Взять кандидатов из ленты tg-feed
```
python3 from_feed.py          # показать новые репо из ленты, которых ещё нет в каталоге
python3 from_feed.py --cmds   # сразу готовые команды add.py для копипаста
```

## Поправить вручную
Открой `catalog.json`, измени запись (описание/категорию/галочку), потом:
```
python3 build_readme.py       # пересобрать README
```

## Категории
Меняются в `catalog.json` → блок `categories`. Ключ (`key`) трогать осторожно — он стоит в записях.
